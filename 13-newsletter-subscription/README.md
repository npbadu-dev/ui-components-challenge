# Newsletter Subscription UI

## Overview

This project is a polished newsletter subscription section designed to encourage visitors to join a mailing list. It combines a clear headline, an email signup form, and a set of feature highlights to make the call-to-action feel engaging and modern.

## Features

- Clean and attractive landing-style layout
- Email input with real-time validation feedback
- Stylish subscribe button with hover effects
- Feature cards highlighting benefits such as exclusive offers, fitness tips, and new arrivals
- Responsive centered design for a smooth viewing experience

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Font Awesome icons

## Project Structure

- index.html: Contains the page structure and content
- style.css: Handles the visual styling, layout, and responsive design
- script.js: Adds client-side email validation feedback

## How to Run

1. Open the project folder in your browser.
2. Launch index.html directly, or use a live server for a better preview experience.
3. Enter an email address in the input field to see the validation state change.

## Purpose

This component is part of a larger UI components challenge and demonstrates how to build a simple yet attractive subscription form with interactive feedback.
