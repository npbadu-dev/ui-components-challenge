# Product Card

A modern product card UI built with HTML and CSS. This component showcases a fitness product with a promotional badge, pricing details, customer reviews, color selection, and an add-to-cart button.

## Features

- Clean product card layout with a highlighted hero image
- "Best Seller" badge and wishlist icon
- Product title, price, discount, and review information
- Color selection options with visual radio buttons
- Hover and active states for the add-to-cart button

## Files

- index.html: Structure of the product card
- style.css: Styling, layout, colors, hover effects, and responsive card design
- script.js: Placeholder JavaScript file for future interactivity
- assets/product-img.png: Product image used in the card

## Preview

Open index.html in your browser to view the component.

## Technologies Used

- HTML5
- CSS3
- Font Awesome icons
