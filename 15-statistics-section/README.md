# Statistics Section

## Overview

This project is the 15th UI component in the challenge: a polished statistics section designed to showcase a brand’s impact and customer trust. It combines bold headline content with metric cards and a supporting footer area that highlights key benefits such as secure payments, fast support, easy returns, and quality assurance.

## Features

- Clean and modern statistics layout with a strong hero heading
- Highlighted metric cards for major achievements and customer numbers
- Support section for showcasing trust and service benefits
- Hover effects and subtle transitions for a more interactive feel
- Soft, professional color palette and balanced spacing throughout

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Font Awesome icons

## Project Structure

- index.html: Contains the page structure for the statistics section and its cards
- style.css: Handles the layout, colors, spacing, card designs, and hover animations
- script.js: Currently empty, but can be used for future interactivity

## How to Run

1. Open the project folder in your browser.
2. Launch index.html directly, or use a live server for a better preview experience.
3. View the statistics cards and explore the visual layout.

## Purpose

This component demonstrates how to present business performance and trust signals in a visually appealing way. It is especially useful for ecommerce, fitness, SaaS, and brand landing pages that want to communicate credibility and impact at a glance.
