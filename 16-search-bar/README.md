# Search Bar

## Overview

This project is the 16th UI component in the challenge: a modern search bar interface designed for product discovery and filtering. It combines a large input field with search and clear icons, a category dropdown, and a prominent action button to create a polished and practical search experience.

## Features

- Clean and visually appealing search bar layout
- Search icon and clear icon for better usability
- Category selector for narrowing search results
- Rounded corners and soft shadow styling for a modern look
- Hover effects on interactive elements for a more dynamic interface

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Font Awesome icons

## Project Structure

- index.html: Contains the structure of the search bar component
- style.css: Handles the layout, colors, spacing, shadows, and hover effects
- script.js: Currently empty, but can be used for future search interactions

## How to Run

1. Open the project folder in your browser.
2. Launch index.html directly, or use a live server for a better preview experience.
3. Interact with the search input, category selector, and action button.

## Purpose

This component demonstrates how to build a refined search experience for ecommerce, dashboards, and content-heavy interfaces. It is especially useful for pages that need a strong and intuitive way for users to find products, articles, or information quickly.
