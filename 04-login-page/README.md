# Login Page UI

This project is a simple front-end UI component that showcases a modern login page for a fitness-themed website. It includes a split layout with a welcome section on the left and a sign-in form on the right.

## Overview

The page includes:
- A polished left-side panel with branding, welcome text, and a supporting illustration
- A login form with email and password fields
- Social sign-in options such as Google, Apple, and Facebook
- A sign-up prompt for users who do not yet have an account
- Styling with rounded cards, soft shadows, and a bold orange accent color

## Features

- Clean and modern authentication layout
- Form fields with visual validation feedback for email input
- Styled divider and social login buttons
- Responsive structure built with plain HTML, CSS, and JavaScript
- Lightweight design with no framework dependency

## Project Structure

- index.html: Main page structure for the login layout and form
- style.css: UI styling, spacing, buttons, form controls, and responsive layout
- script.js: Email input validation logic for visual feedback
- assests/hero-img.png: Illustration used in the left side of the page

## How to Run

1. Open the project folder in your browser.
2. Launch index.html directly, or use a simple local server such as Live Server.
3. Review the login interface and test the email field behavior.

## Technologies Used

- HTML
- CSS
- JavaScript
- Font Awesome icons

## Notes

This component is currently a static UI demo. The form is designed for presentation and does not submit data to a backend.
