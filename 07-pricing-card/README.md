# Pricing Card

A polished pricing plan UI built with HTML and CSS. This component presents three subscription tiers for a fitness-focused product, with a highlighted "Pro" plan, clear feature lists, and a trust-building footer section.

## Features

- Clean hero section introducing the pricing experience
- Three pricing cards for Basic, Pro, and Elite plans
- A visually emphasized "Most Popular" badge on the Pro plan
- Clear monthly pricing, feature highlights, and call-to-action buttons
- Hover effects and modern card styling for a more interactive feel
- A footer section featuring a 30-day money-back guarantee

## Files

- index.html: Main structure of the pricing page
- style.css: Layout, colors, card styles, hover transitions, and footer design
- script.js: Placeholder JavaScript file for future interactivity
- README.md: Project documentation
