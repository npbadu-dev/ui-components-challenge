# Contact Form

A polished contact form UI built with HTML, CSS, and a small amount of JavaScript for email validation.

## Overview

This project presents a clean and modern contact form experience with a welcoming introduction, a styled contact card, and a simple form layout. It uses soft colors, rounded elements, and Font Awesome icons to create a friendly and professional look.

## Features

- a hero-style intro section with a friendly heading and description
- a contact card layout with a clear form header
- input fields for full name, email, subject, and message
- a checkbox for agreeing to the terms and privacy policy
- real-time email validation with visual success and error states
- a styled submit button with hover feedback

## Files

- `index.html` — the page structure and form markup
- `style.css` — the layout, colors, spacing, and form styling
- `script.js` — the email validation behavior
- `README.md` — project documentation

## How to view

1. Open `12-contact-form/index.html` in your browser.
2. Make sure you have internet access so the Font Awesome icons can load from the CDN.

## Notes

- The form is presented as a static UI demo.
- The submit button currently uses a placeholder form action and does not send data to a backend.
- The JavaScript enhances the email field by showing whether the typed value looks valid.
