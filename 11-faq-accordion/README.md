# FAQ Accordion

A static FAQ accordion component built with HTML and CSS.

## Overview

This component shows a frequently asked questions section with a featured open
item and a list of additional questions below it.

It uses:

- semantic HTML structure for FAQ items
- styled containers and cards in `style.css`
- Font Awesome icons for question markers and toggle symbols

## Files

- `index.html` — the component demo page
- `style.css` — layout and visual styling
- `script.js` — currently empty; no interactive behavior is implemented
- `README.md` — this documentation

## Features

- prominent FAQ heading and introduction
- first question shown as active with answer text
- additional questions listed below with plus icons
- consistent card styling with shadows, rounded corners, and hover states
- mobile-friendly layout using flexible columns and spacing

## How to view

1. Open `11-faq-accordion/index.html` in a browser.
2. Ensure internet access for the Font Awesome CDN icons.

## Notes

- The component currently renders as a static accordion layout.
- `script.js` is present but empty, so question toggling is not yet wired up.
- To complete the experience, add JavaScript to toggle the plus/minus icons and
  expand or collapse answer content on click.
