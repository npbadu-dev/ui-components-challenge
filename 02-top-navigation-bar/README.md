# Top Navigation Bar UI

This project is a simple front-end UI component that showcases a modern top navigation bar with a brand logo, navigation links, and a search field.

## Overview

The page includes:
- A clean header with a horizontal navigation bar
- A brand/logo section labeled "PixelFit"
- Menu links for Home, Products, About Us, and Contacts
- A search input styled as part of the navigation bar
- Soft shadowing, rounded corners, and hover transitions for a polished look

## Features

- Clean and minimal navigation layout
- Hover effects for links and logo
- Search bar integrated into the navbar
- Responsive structure built with plain HTML, CSS, and JavaScript
- Lightweight styling with no framework dependencies

## Project Structure

- index.html: Main layout for the navigation bar
- style.css: Visual styling, spacing, hover states, and search bar appearance
- script.js: Placeholder script file for future interactivity

## How to Run

1. Open the project folder in your browser.
2. Launch index.html directly or use a local server such as Live Server.
3. Review the navigation bar layout and interact with the links and search field area.

## Technologies Used

- HTML
- CSS
- JavaScript
- Font Awesome icons

## Notes

The component is currently a static UI demo. The JavaScript file is included for future enhancements such as menu interactions or search behavior.
