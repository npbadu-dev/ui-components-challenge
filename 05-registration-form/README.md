# Registration Form UI

This project is a modern registration form built with HTML, CSS, and JavaScript. It includes a clean layout, responsive form fields, email validation, and password visibility toggles.

## Features

- Responsive registration page layout
- Styled input fields and form controls
- Email validation feedback
- Show/hide password toggle for both password fields
- Social sign-up buttons and navigation links

## Project Structure

- `index.html` - Main markup for the registration form
- `style.css` - Styling for the full page layout and form elements
- `script.js` - JavaScript for form validation and password toggling
- `assests/` - Images and other assets used in the UI

## How to Run

1. Open the project folder in your browser.
2. Open `index.html` directly or use a simple local server.

Example:

```bash
cd 05-registration-form
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
