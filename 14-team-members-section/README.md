# Team Members Section

## Overview

This project is a polished team members section designed to showcase the people behind a brand or product. It presents team profiles in a modern card layout with photos, roles, short descriptions, and social icons, along with a supporting stats footer.

## Features

- Clean and modern team showcase layout
- Profile cards for each team member with image, name, role, and short bio
- Hover effects for a more interactive experience
- Social media icon styling for each profile
- A summary footer highlighting company achievements and team strength
- Responsive layout centered around a visually appealing card grid

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Font Awesome icons

## Project Structure

- index.html: Contains the full structure of the team section and footer
- style.css: Handles the layout, colors, spacing, hover effects, and card styling
- script.js: Currently empty, but can be used for future interactivity
- assets/: Stores the team member images used in the cards

## How to Run

1. Open the project folder in your browser.
2. Launch index.html directly, or use a live server for a better preview experience.
3. Browse the team cards and interact with the hover effects.

## Purpose

This component is part of a UI components challenge and demonstrates how to build an attractive team introduction section that feels professional, friendly, and visually engaging.
