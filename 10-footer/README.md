# Footer Section UI

This project is a polished footer component designed for a modern fitness and lifestyle brand. It presents a complete footer experience with branding, feature highlights, product/company/help navigation, newsletter signup, app download prompts, social links, and bottom policy information.

## Overview

The page includes:

- A branded intro area with the company logo and short description
- Feature cards highlighting premium quality, fast delivery, easy returns, and support
- Multiple navigation sections for shop, company, and help/support links
- A newsletter subscription call-to-action with an email input and send icon
- App download buttons for Google Play and the App Store
- Social media links and a bottom policy bar

## Features

- Clean and modern footer layout with strong visual hierarchy
- Rounded cards, soft color accents, and hover effects
- Responsive spacing and typography for a refined presentation
- Built with plain HTML and CSS using Font Awesome icons and Google Fonts

## Project Structure

- index.html: Main structure of the footer section
- style.css: Layout, colors, spacing, hover states, and visual styling
- script.js: Placeholder script file for future interactivity

## How to Run

1. Open the project folder in your browser.
2. Launch index.html directly, or use a local development server such as Live Server.
3. Review the footer UI and its layout sections.

## Technologies Used

- HTML
- CSS
- JavaScript
- Font Awesome icons
- Google Fonts

## Notes

This is a static UI component demo focused on layout composition, spacing, and visual design. The current implementation emphasizes presentation and styling rather than dynamic functionality.
