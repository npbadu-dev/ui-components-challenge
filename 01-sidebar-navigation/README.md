# Sidebar Navigation UI

This project is a simple front-end UI component that showcases a modern sidebar navigation layout with a dark/light theme toggle and interactive menu states.

## Overview

The page contains:
- A fixed sidebar with a brand section and navigation links
- A main content area with multiple section blocks
- A theme toggle button that switches between dark and light themes
- Clickable nav items that visually become active when selected

## Features

- Clean sidebar layout with icons and labels
- Hover and active states for navigation links
- Theme switching using CSS variables
- Lightweight JavaScript for interactivity
- Responsive structure built with plain HTML, CSS, and JavaScript

## Project Structure

- index.html: Main page structure and sidebar markup
- style.css: Layout, spacing, hover effects, and sidebar styling
- variable.css: Theme color variables for dark and light modes
- script.js: Theme toggle behavior and active nav link handling

## How to Run

1. Open the project folder in a browser.
2. Launch index.html directly, or use a simple local server such as Live Server.
3. Click the theme toggle to switch modes.
4. Click any navigation item to highlight it as the active link.

## Technologies Used

- HTML
- CSS
- JavaScript
- Font Awesome icons

## Notes

The navigation links are styled as UI elements for this demo and currently do not navigate to separate pages.
