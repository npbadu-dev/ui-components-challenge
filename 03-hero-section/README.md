# Hero Section UI

This project is a simple front-end UI component that showcases a modern hero section for a fitness-themed landing page. It combines a polished navigation bar, a bold headline, call-to-action buttons, feature highlights, and a visual illustration.

## Overview

The page includes:
- A top navigation bar with a brand name, menu links, and a search field
- A large hero section with a strong headline and supporting text
- Two action buttons for shopping and exploring product collections
- Feature highlights for premium quality, fast delivery, and easy returns
- A hero image styled with rounded corners and shadow effects

## Features

- Clean and modern hero layout
- Bold typography with highlighted accent color
- Hover effects on buttons and links
- Feature cards with icons for quick product benefits
- Responsive structure built with plain HTML, CSS, and JavaScript

## Project Structure

- index.html: Main structure for the navigation and hero section
- style.css: Layout, spacing, typography, buttons, and visual styling
- script.js: Placeholder script file for future interactivity
- assests/hero-img.png: Hero illustration image used in the section

## How to Run

1. Open the project folder in your browser.
2. Launch index.html directly, or use a simple local server such as Live Server.
3. Review the hero section layout and its visual elements.

## Technologies Used

- HTML
- CSS
- JavaScript
- Font Awesome icons

## Notes

This component is currently a static UI demo. The JavaScript file is included for future enhancements such as interactive menu or button behavior.
