# Testimonial Section UI

This project is a polished front-end UI component that showcases a testimonial section for a fitness and lifestyle brand. It presents customer reviews in a clean card layout with a strong heading, highlighted trust metrics, and a polished visual style.

## Overview

The page includes:

- A centered hero-style introduction with a branded title pill
- Three testimonial cards featuring customer feedback, ratings, and product details
- A simple navigation bar with left/right arrow controls and indicator dots
- A footer summary section highlighting key trust statistics such as customer count, ratings, reviews, and recommendations

## Features

- Modern testimonial card layout with rounded corners and soft shadows
- Star ratings and quote-style visual accents for a premium feel
- Responsive spacing and typography for a clean presentation
- Simple interactive UI elements such as navigation icons and selection dots
- Built using plain HTML, CSS, and JavaScript

## Project Structure

- index.html: Main structure of the testimonial section
- style.css: Layout, colors, spacing, card styling, and responsive design
- script.js: Placeholder script file for future interactivity
- assests/: Image assets used in the testimonial cards

## How to Run

1. Open the project folder in your browser.
2. Launch index.html directly, or use a local development server such as Live Server.
3. Review the testimonial section and interact with the UI controls.

## Technologies Used

- HTML
- CSS
- JavaScript
- Font Awesome icons

## Notes

This is a static UI component demo designed to practice layout composition, card design, and visual hierarchy. The current implementation focuses on presentation and styling rather than dynamic functionality.
